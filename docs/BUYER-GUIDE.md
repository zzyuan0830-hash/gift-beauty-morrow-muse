# Morrow & Muse · 网站产品说明 / Buyer guide

## 交付的是什么
英文精品礼赠商城网站源码与概念设计方案，Next.js + TypeScript，响应式编辑风格。默认展示品牌为 Morrow & Muse，奶油白、深莓果红、香槟色，九个概念商品覆盖固定礼盒、香氛和身体护理。

这是可运行、可修改、可交接的网站软件。概念模式不收费、不创建订单；Shopify 接口已实现并用本地契约测试验证，尚未连接实际店铺。不是已运营、已有收入或已有真实商品的网站生意。

## 五分钟演示路径
1. 首页 `/`：大幅概念图、礼盒推荐、分类、礼赠场景、品牌故事。
2. `/gifting`：选择 “A gift to open together” 和 “$50 or less”，显示 The Little Thank You；刷新保留选择。选择 fragrance + $50 查看无结果和重置。
3. `/shop`：搜索、分类、价格区间和排序；打开任一商品详情。
4. `/products/the-slow-sunday`：看图片、点击放大、方向键切图、Esc 关闭；查看内容物、规格方向和包装说明。
5. 将 The Slow Sunday 数量2及 Fig & Paper 数量1加入预览购物袋，合计为 $210；修改、删除、刷新，检查本机保存。
6. `/bag` 的 “About this preview” 如实说明不收款、不创建订单；不会跳到假的付款成功页。
7. 手机查看导航菜单、商品图、底部商品入口、送礼筛选。最后检查 FAQ 和四个独立的信息页。

所有概念价格均为示意。商品图片是 AI 概念图及原创插图，不是实物摄影。不是每款都有三个不同拍摄角度；现有覆盖详见 ASSETS.md。

## 所含功能
完整首页、商品目录、9个可直达详情、偏好/预算送礼指南、购物袋、About、FAQ、配送/退货/隐私/条款说明、404、加载和错误状态；桌面/平板/手机布局；图片弹层和移动菜单的键盘支持；减少动态效果；本地素材；明确的数据源与交易隔离；后续 Shopify 托管结账接口。

本版本销售范围为单品和固定礼盒；自选组盒、赠言、付费包装、会员和营销系统不在本版本范围。

## 买方接手
先按 README 安装与运行概念模式 → 按 CUSTOMIZATION 修改品牌与商品 → 保留概念标识直到真实资料齐备 → 如经营实物商城，按 SHOPIFY-SETUP、LIVE-ACCEPTANCE 和 RELEASE 接入与验收。

用户可自行介绍或转让本网站工程，但定价、合同、源代码和资产授权范围、是否独占、售后维护均需由交易双方明确。本任务没有联系买家或对外挂牌出售。
