# 日常订单操作手册

此手册待独立店铺联调确认后台实际界面。当前没有真实订单。

1. 在 Shopify Orders 核对商品 SKU、数量、USD 金额、支付状态、风险提示、配送地址和所选运费。只有满足经营方发货规则的已确认付款订单才交仓；截图或顾客前端“成功”字样不是收款证据。
2. 首版人工履约：按整盒或单品 SKU 发送仓库拣货单，核对承运线路。私密客户资料仅在授权系统中处理，不放项目 Git、日志或测试附件。
3. 实际发货后，在 Shopify 录入承运商与追踪单号，再执行 fulfil/发送通知。不得在未发货时伪造运输状态。
4. 缺货/地址不可达时，通过真实客服渠道联系并按政策处理。库存变更以 Shopify 为准；定期盘点整盒与单品库存，避免重复占用。
5. 取消或退款前核实是否已发货、退款金额、运费退还规则及是否需要回补库存。部分退款按 SKU/数量核对，不能自动把已使用/丢损商品回库存。
6. 在支付服务商核对退款状态、结算批次、手续费、币种和银行实际到账；Shopify 订单记录不能代替银行对账。
7. 拒付与退货保留合法必要的付款、物流和沟通记录，按已审核政策及服务商时限处理。

上线前必须由运营人员走完：测试订单→付款状态核对→通知→仓库交接→追踪号→部分退款→全额退款/取消→库存检查→对账。真实小额付款退款需要明确授权，退款未必退回所有手续费。

监测：Vercel 请求/错误率与仅含事件码、随机 request id 的应用日志；Shopify 后台订单/支付失败与库存。不得记录私有 token、购物车 key、完整 GraphQL 变量、收件资料或支付信息。未配置外部报警联系人/服务，不声称有人值守。
