# 成品网站交付目标 · V4

用户已调整目标：先完成可展示、可交付、可由后续买方接手的网站产品；使用概念资料。供应商名单、询价、打样和真实业务接入延后，不作为本阶段完成条件。

## 本阶段范围
1. 保留 v2/v3 已恢复的奶油白、莓果红、大幅原创概念图和完整页面。
2. 补强送礼指南：图像叙事、偏好与预算筛选、可直达并刷新保持的结果、无结果与重置，使用共用商品来源。
3. 统一概念模式 FAQ/政策说明，将打样和供应商内部材料从购物流程移出；保留清楚的概念与不收款标识。
4. 将概念商品与品牌标识整理为明确的配置入口，交付买方演示路径、修改指南、资产权利说明和迁移清单。
5. 生产构建、类型/单元/浏览器测试，桌面、平板与约390px手机自测，保存新截图和可安装的完整交付包。

## 验收边界
网站产品验收：完整英文页面、真实可操作的浏览/选品/本地购物袋流程、无虚构支付成功、可安装可构建、有源码与运行包、有实际测试证据。
未来营业验收：独立 Shopify、真实商品/图片、支付和履约的真实联调另行完成。不得将前者写成后者已完成。

出售对象可描述为网站源码、界面设计及概念展示方案；不包含在营店铺、客户、收入、供应商合同、注册商标或独占资产保证。具体售价、交易和权利转让由用户决定，当前不对外刊登或联系买家。

## 顺序
先记录本计划 → 实现页面和交接配置 → 自测并修复 → 截图及打包 → 用户验收。原 v2 和历史交付包不覆盖；无外部部署和购买。
